# Гофермарт — накопительная система лояльности

HTTP API сервис для накопления и списания бонусных баллов за заказы в интернет-магазине.

## Описание

Пользователь регистрируется, загружает номера заказов, система начисляет баллы через внешний accrual-сервис. Баллами можно оплачивать новые заказы (1 балл = 1 рубль).

## Стек

- Go, Gin, PostgreSQL, JWT, goose (миграции)

## Конфигурация

Сервис настраивается через переменные окружения или флаги CLI:

| Переменная окружения     | Флаг | Описание                           |
|--------------------------|------|------------------------------------|
| `RUN_ADDRESS`            | `-a` | Адрес и порт сервиса               |
| `DATABASE_URI`           | `-d` | Строка подключения к PostgreSQL    |
| `ACCRUAL_SYSTEM_ADDRESS` | `-r` | Адрес системы расчёта начислений   |
| `JWT_SECRET`             | `-s` | Секрет для подписи JWT-токенов     |
| `LOG_LEVEL`              | `-l` | Уровень логирования (info, debug, error) |

## Запуск

### Инфраструктура (PostgreSQL через Docker)

```bash
make infra-up
```

### Сервис

```bash
make run
```

Или вручную:

```bash
go run cmd/gophermart/main.go \
  -a :8080 \
  -d "postgres://gophermart:gophermart@localhost:5432/gophermart?sslmode=disable" \
  -r http://localhost:8081
```

## Сборка

```bash
make build
```

Бинарник создаётся в `cmd/gophermart/gophermart`.

## Тестирование


## API

Все защищённые эндпоинты требуют JWT-токен в заголовке `Authorization: Bearer <token>` или cookie `token`.

| Метод | Путь                         | Авторизация | Описание                      |
|-------|------------------------------|-------------|-------------------------------|
| POST  | `/api/user/register`         | —           | Регистрация пользователя      |
| POST  | `/api/user/login`            | —           | Аутентификация                |
| POST  | `/api/user/orders`           | +           | Загрузить номер заказа        |
| GET   | `/api/user/orders`           | +           | Список заказов с начислениями |
| GET   | `/api/user/balance`          | +           | Текущий баланс                |
| POST  | `/api/user/balance/withdraw` | +           | Списать баллы                 |
| GET   | `/api/user/withdrawals`      | +           | История списаний              |

### Статусы заказов

- `NEW` — принят, ещё не обработан
- `PROCESSING` — в обработке
- `PROCESSED` — обработан, баллы начислены
- `INVALID` — не принят к расчёту
